Professor Demonstration Attack Matrix

Live Attack Suite

Trigger any of the 6 mandatory attack scenarios with a single click. The client verification engine intercepts each attack and fails-secure at the exact cryptographic boundary.

Scenario 1 — Successful Update
Genuine DemoApp 1.1.0 update. SHA-256 and Ed25519 signature valid. Candidate strictly newer.
Scenario 2 — Package Tampering
Adversary modifies a file or injects byte payload inside the ZIP package after signing. Client detects SHA-256 mismatch.
Scenario 3 — Unauthorized Publisher
Attacker generates rogue Ed25519 keypair and signs a malicious update. Client rejects untrusted signature.
Scenario 4 — Rollback Attack
Client is on v1.1.0. Attacker replays genuine, validly-signed v1.0.0 release. Client rejects older version.
Scenario 5 — Metadata Tampering
Adversary modifies package hash in release.json but retains original signature. Ed25519 verification fails.
Scenario 6 — Expired Release
Attacker supplies a signed release whose expiration timestamp has passed. Expiration check blocks installation.
